# Contributing to Flangx

We welcome your help to improve this project! Please note that while the source code is proprietary, we encourage the community to help make it better.

## How Can I Contribute?

### Reporting Bugs
* Check the existing issues to see if the bug has already been reported.
* If not, open a new issue. Include as much detail as possible: steps to reproduce, what you expected to happen, and what actually happened.

### Suggesting Enhancements
* Open an issue to discuss your idea.
* Clearly describe the feature and how it would benefit the project.

### Submitting Fixes
* Since this project has strict usage and copying restrictions (see [LICENSE.md](LICENSE.md)), we recommend discussing any major changes through an issue before writing code.
* If you find a bug and have a fix, feel free to submit a Pull Request.

## Code Standards
* Keep code clean and efficient.
* Strip internal comments from final submissions to maintain the "shipping" look of the repository.
* Ensure code is compatible with the .NET 4.0 / C# 5.0 compiler environment.

## Ground Rules
* Be respectful to others.
* Follow our [Code of Conduct](CODE_OF_CONDUCT.md).
* By contributing, you agree that your contributions will be licensed under the project's custom license.
